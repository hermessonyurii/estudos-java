# ☕ Estudos e Fundamentos em Java

Criei este repositório dedicado a minha evolução contínua em desenvolvimento de software, guardando os meus exercícios práticos e algoritmos em Java. O objetivo é consolidar a base da lógica de programação e estruturação de código.
Pode parecer simples, porém! cada degrau que eu subo, mais próximo do TOPO...

## ✈️ Tecnologias e Ferramentas
- **Linguagem:** Java
- **IDE:** Eclipse
- **Controlo de Versões:** Git e GitHub (com estrutura multi-projetos no Workspace)

## 🧠 Tópicos Abordados até ao momento
- Estrutura básica de um programa Java (Classes e Métodos `main`).
- Declaração de Variáveis e Tipos de Dados (`int`, `double`, `String`).
- Entrada de Dados pelo teclado utilizando a classe `Scanner` (e gestão da limpeza de buffer).
- Manipulação de casas decimais e formatação de saída com `Locale` e `printf`.
- Operadores aritméticos e cálculo de fórmulas matemáticas (Áreas, geometria e regras de negócio simples).
- Estruturas condicionais (`if` / `else`) para controlo de fluxo e validações.
- Estruturas de repetição (`for`) para iterações e automação de processos.
- Lógica com Contadores, Acumuladores e cálculos complexos (Fatoriais, Divisores).
- Conversão explícita de tipos de dados (*Casting*) e operador de módulo (`%`).
- **Introdução à Programação Orientada a Objetos (POO):** Criação de Classes, Atributos e Métodos personalizados.
- **Instanciação de Objetos:** Separação de responsabilidades entre a classe de domínio (molde) e a aplicação principal.
- **Estruturas de Dados (Vetores/Arrays):** Armazenamento e manipulação de múltiplos dados usando vetores para tipos primitivos e vetores de Objetos.
